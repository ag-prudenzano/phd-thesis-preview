# PhD Thesis Preview

Can speaking in Discord voice channels support offline social confidence and engagement among adults with elevated social anxiety?

This repository contains a public preview of Andrea Prudenzano’s three-study mixed-methods PhD research examining whether speaking in Discord voice channels predicts offline social confidence and voluntary face-to-face engagement among socially anxious adults.

The project is a real research project and is currently in progress.

Read the full [`report.md`](report.md) for the conceptual model, four proposed pathways, and study design.
